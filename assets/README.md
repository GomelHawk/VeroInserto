# Logos

Two files live here, and nothing else: `logo.png` (1024×1024, the icon above the wordmark)
and `horizontal-logo.png` (1024×368, the icon beside the wordmark and the slogan). The
README shows the horizontal one; VeroPlugins' catalog cuts its table icon from the square
one. Make both from your drafts with VeroPlugins' `scripts/logos.py`, which puts any pair
on the standard canvas, icon height, wordmark height and background; the sizes and the
background colour are written down in VeroPlugins' `STANDARD.md`. The two files here
are placeholders: replace them before the first release.
